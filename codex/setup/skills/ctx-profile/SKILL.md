# ctx-profile · codex

动作是 agent 的内部分类；用户直接用自然语言表达即可，无需说出技能名或动作名。只有明确要求保存时才写入长期内容。

只保留此统一入口，按本次意图选择流程，不预先加载全部资料：

- 保存或查找核心论断、精彩表达、个人想法摘录：读 [核心论断流程](../../../../workflows/profile-insights.md)，使用 [核心论断工具](../../../../scripts/profile_insights.py)。
- 个人配置、旧历史议题与全局事项：按 [共用流程](../../../../workflows/profile.md) 只读对应一节：`init`、`show`、`update`、`adapt`、`export`、`topic`、`task`。无明确意图默认只读 `show`。

使用 [主档工具](../../../../scripts/profile_tool.py) 和按需使用的 [历史读取工具](../../../../scripts/profile_history.py)。链接相对本文件解析，执行前取得脚本绝对路径；`--root` 使用用户指定根目录，未指定时为 `~/.context-kit/`。脚本只用标准库，不依赖源码 checkout。

查看和查询不保存；长期配置、topic/task 仅按明确写入意图处理。已有授权直接执行相应写入，无需重复确认。adapt 仅处理明确选择的平台；文件生成、入口配置和原生加载验证分别报告，不重建已清理的 Claude 环境。主档不复制项目状态，技能安装目录不存个人主档。
