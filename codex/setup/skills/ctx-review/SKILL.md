# ctx-review · codex

用户可说 `ctx-review to claude` 或直接说明目标，不要求子命令。聚焦整体判断、实质异议和更好的方案，不默认逐句校对、逐链接核验或重复已有验证。

- **送审/回收方**：读[共用流程](../../../../workflows/review.md)和[平台适配](../../PLATFORM.md)的方案送审部分；CLI 调用、轮次、版本与运行记录由调用方处理，材料归被审项目。
- **收到自足请求的审核方**：直接按请求评议，给出理由与取舍；不必再读整套流程，不接管原案，不重复检查哈希和身份。只输出正文或指定独立回执。

以上引用相对此文件解析，不相对用户 cwd。
