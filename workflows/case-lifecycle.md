# 案的结案与恢复

按 [METHOD 的案生命周期](../docs/METHOD.md#案生命周期) 判定终态与保留范围。这是现有技能的共用分支，不是新 skill 或用户必须记住的子命令。

## 识别意图

| 用户表达 | 处理 |
|---|---|
| “换个会话继续”“交接这个案” | [交接](handoff.md)，工作仍继续 |
| “C-07 做完了，结案” | 本流程结案，类型完成，核对交付证据 |
| “C-07 不用了”“废弃/终止 C-07” | 本流程结案，类型终止 |
| “这些案已被 C-14 替代”并要求结束 | 逐案终止，记录实际替代关系；不凭替代二字假称任务已被接收 |
| “把 C-07 合并到 C-14” | 本流程结案，类型合并，确认承接 |
| “哪些旧案不用了”“看看已结束的案” | [状态查询](status.md)，仅列候选/历史 |
| “重新做/恢复/重开 C-07” | 本流程恢复；接受自然表达，不要求再说固定口令 |

只有“结束/收口”且对象或结果不明时，结合上下文判断；确实分不清交接、完成还是终止，只问这个必要问题。用户明确要求的动作直接执行，不重复确认。判断“目标已达到”或“看起来已不用”只够提出建议，不等于用户授权结案。

## 结案

1. **定位与写入者。** 确定项目/子项目、权威案路径及目标 ID，读案头、A/B/D/E/H/I、记录文件中相关的 C/E/F/G 行和离线收件。示例不是目标名单。同项目匹配多个文件时不能任选；保留当前路径，不搬案。按既有持笔与并发规则处理：其他会话仍持笔时协调收口或投递独立请求，不借结案抢笔。只有在已有授权和写入归属明确后才修改案；不能从旧时间戳推定无人写入。
2. **幂等与类型。** 已结案且重复同一请求时，核对新增异常后报告已有结果，不改原结案时间、类型或任期。用户明确更正原因时追加更正记录。确定完成/终止/合并：完成须有目标与交付证据，不足就报告待核实；合并须目标存在、非自身、处于可承接工作的活跃状态，并明确谁承接哪些事项。同一批中也要结束的案不能作为新转交目标；目标无效或尚未接收不能记已合并。历史替代关系可以引用已结束案，但不据此宣称它正在承接新工作。
3. **开始收尾。** 重读案头确认未被改变，再写案状态“结案中”、交接“收口中”，记录拟结案类型和用户给出的原因，保留现任持笔。在 F 记录本次请求。批量中一个案受阻不阻止处理其余已明确、可安全完成的案。
4. **逐项安置。** 保存交付与证据，为未解决 D、未完成 E、H 缺口、I/离线来件（含记录文件中仍在跑或未处置的行）逐项填写 H 的结案处置（事项 ID、完成/停止/转交/保留未验证、去向或证据）。E 使用实际状态：完成、取消、已转交；历史失败/部分结果保留，不能把取消写成完成。I 保留原消息，拒绝的记不采纳及原因，转交的带目标消息 ID 和接收证据。已转交事项在原案停止跟进，但原始身份和交付链保留。
5. **核对执行与异常。** 按已知载体/平台核对是否还在跑、待验收或待接收。记录“取消”不会停止进程；实际停下或已被承接后才算处置完成。工具/授权不足、状态未知而影响结案、仍在写的执行者、无人接收的转交、未处置来件均保留结案中，列出具体缺口。只保留信息价值且已明确停止跟进的未验证项可以随终止案保留，不要求为废弃方向补做全部实验。
6. **完成并同步。** 重读案头、相关任务和收件，确认收尾完成；写入已结案、类型、时间、原因及已有的关联案。记录前任身份，清空现任持笔平台/ID/名称等字段，交接设已结束；保留任期。B 简述结果与承接位置，决策记录与过程记录追加结案决定与处置证据。更新板的本案状态/持笔投影，将完整行移到同一案索引表末尾，保留短名、路径和全部列；按未转义管道分列。同步失败按“案已结案、板待同步”等实际状态报告，重试补投影，不重做结案或增加任期。

回复列出已结案、仍在收尾、定位失败的案及原因；类型完成时才称目标完成。结案后当前聊天可处理其他工作，不自动改名为退役、归档聊天、提交推送或创建接手会话。

## 恢复

1. 查询/审查旧案只读。单独说“接手 C-07”而未表明知道它已结束时，先说明结案原因，确认是否恢复；已明确“重新做/恢复”的不再问一次。
2. 核对案头及收尾异常。残留其他持笔、仍在写的执行者或未完成转交先按并发/转交规则解决。已完成的转交不撤回，恢复时只选择本次确需重新推进的事项。
3. 写入前重读头部，将上次结案类型、时间、原因、关联案完整保留到 F；写案状态讨论中、交接候接手、当前结案字段为无，保留原案号与任期。更新 B/D/E，明确哪些事项恢复，旧终止记录不删除。
4. 进入 [接手流程](takeover.md) 的身份/任期认领步骤，正式接手只加一次任期并同步案/板/标题。恢复过程中失败则保留实际已完成阶段；重试先读案头，已恢复且当前身份仍持笔时沿用任期。缺任期的旧案依共用兼容规则首次初始化 01。
